# Figure data

Each folder holds one manuscript figure (PDF, and PNG where available) together
with the CSV file(s) it is plotted from.

| Figure | CSV source(s) |
|---|---|
| `fig_A_predicted_vs_real` | `fig_A_data.csv`, `cao_reported_rates.csv`, `data_key_rate_vs_mu.csv` |
| `fig_B_Ep_vs_mu` | `data_Ep_Ez_vs_mu.csv` |
| `fig_G1_mu_landscape_merged` | `fig_G1_mu_landscape.csv` |
| `fig_G2_combined` | `fig_G2_optimal_mu.csv`, `fig_G3_joint_opt.csv` |
| `fig_F_li_kato_vs_azuma` | `fig_F_li_kato_vs_azuma.csv` |
| `fig_IR_keyrate_vs_pIR` | `ir_attack_sweep.csv` |
| `fig_IR_visibility_check` | `ir_attack_sweep.csv` |
| `fig_USD_combined` | `usd_attack_sweep.csv` |
| `fig_USD_Ep_mechanism` | `usd_ep_mechanism.csv` |

`cao_reported_rates.csv` contains the experimental key rates reported by Cao et al.
(2026); all other CSVs are simulation output from this framework.
